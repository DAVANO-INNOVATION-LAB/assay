A model is executable code. Scan it like one.

Zeus reads model artifacts the way the loader will: it parses the serialization format, finds every path by which weights execute code, and stops the model at the cluster door. Built into the OpenShift AI Model Registry, so a model is inspected the moment it is registered.

Format coverage

Risk is a property of the format, before any file is examined.

Some serialization formats cannot execute code at all. Others do it by design. Zeus classifies the artifact first, so a policy can refuse an entire format class rather than playing whack-a-mole with individual payloads.

FormatClassWhy
safetensorsSafe by designTensor data plus a JSON header. No deserialization callback, no code path.
gguf / ggmlSafe by designFlat quantized tensor container with no executable section.
onnxConditionalGraph is declarative, but custom and contrib operators load out-of-tree code during inference.
tensorflow SavedModelConditionalCan embed arbitrary ops and Python functions in the graph.
keras .h5ConditionalLambda layers carry serialized Python that executes on load.
pytorch .pt / .pth / .binExecutes on loadtorch.load unpickles by default; the archive holds a pickle stream.
pickle / joblib / dillExecutes on loadArbitrary code execution is the documented behaviour of the format.
numpy .npyConditionalNumeric arrays are inert; object-dtype arrays are stored as pickles.

Why classification is not enough on its own

Attackers rename files, so extension alone proves nothing. Zeus sniffs headers — an ELF binary behind vocab.txt.dat is still an ELF binary. Conversely, a raw tensor dump contains every pickle opcode byte purely by chance, so detection keys on the protocol magic and the declared format rather than on byte coincidence. A scanner that cries wolf gets switched off.

How it works

Registration triggers the scan. Deployment enforces the verdict.

Zeus integrates with the Model Registry API rather than watching ImageStreams, so a model is caught the moment it is declared — wherever the weights live: S3, ODF, a PVC, an OCI registry, or a ModelCar image.

01

Register

A model version lands in the OpenShift AI Model Registry.

02

Resolve

The connector reads the artifact URI and stages the weights.

03

Scan

One isolated Job per scanner: format, malware, CVEs, SBOM, secrets.

04

Judge

Findings consolidate into a verdict and a risk score.

05

Publish

The verdict returns to the registry as model properties.

06

Gate

Admission refuses model deployments that fail policy.

The model inspector

Reading weights the way the loader will.

Pickle

Opcode and import analysis

Walks the pickle stream for GLOBAL, REDUCE, and STACK_GLOBAL, and for imports that turn a load into RCE — including pickles nested inside torch.save archives.

Tensor formats

Header integrity

Safetensors header length checked against real file size, tensor offsets bounds-checked, and numpy object-dtype arrays surfaced as the pickles they actually are.

Graph formats

Operator inspection

Flags ONNX graphs referencing PythonOp, contrib domains, or custom operators, and external-data references that point outside the model directory.

Model repo

Config and companion code

trust_remote_code, auto_map, and the Python modules they reach — shell-outs, dynamic evaluation, network egress, and compiled CUDA extensions built at import.

Packaging

Archive containment

Zip slip, symlinks escaping the model directory, entry-count ceilings, and compression-ratio limits — all bounded, so a hostile artifact cannot exhaust the pod examining it.

Evasion

Header sniffing

ELF, PE, and Mach-O binaries plus interpreter directives hiding behind harmless model file extensions, caught by magic bytes rather than by filename.

NIST AI RMF 1.0

Framework reporting that will survive an audit.

Zeus assesses every scanned model version against the AI RMF Core and writes the result to the cluster as a ComplianceReport. What it will not do is claim more than it can see. The AI RMF is a voluntary organizational risk-management framework, not a technical control baseline — most of it describes things no scanner can observe.

MEASURE 2.7

Security and resilience

The subcategory Zeus exists to satisfy: malware, known vulnerabilities, embedded secrets, and unsafe serialization evaluated on every version, retained as cluster resources.

MANAGE 1.4

Residual risk documented

A waived policy violation is the unmitigated risk set. Each one records what was accepted, by whom, and until when — which is precisely what this control asks for.

MANAGE 3.2

Pre-trained models monitored

Monitoring third-party pre-trained models as part of regular maintenance is the product's exact purpose, so this one maps cleanly rather than by stretch.

What the report refuses to do

A control that no scanner can observe — that staff are trained, that a diverse team reviewed a decision — can never come back Satisfied from a scan. It requires a named attestation with an expiry, or it stays open and visible.

Nothing is inferred across trustworthiness characteristics. A clean security scan says nothing about fairness, so MEASURE 2.11 stays open until bias evaluation ships in Phase 2. Every assessment also publishes the characteristics it did not measure — validity, behavioural safety, explainability — because MEASURE 1.1 asks for exactly that, and because a coverage claim without it is a lie of omission.

Blast radius

The container holding the model holds no credentials.

A scan pod is handling weights that may be actively hostile. The work splits into three steps with different privileges, ordered so only the last can reach the API server.

init 1

fetch

Resolves the artifact URI and stages the weights. Holds registry and storage credentials. No cluster API access.

init 2

scan

Reads the model. No credentials of any kind, read-only root filesystem, all capabilities dropped, non-root.

main

publish

Writes one scan report. Its ServiceAccount can create exactly that one resource type and nothing else.

Why the ordering matters

Because fetch and scan are init containers, publish only starts once both have exited. The step touching the model never runs concurrently with the step holding a token, so an exploit triggered by a malicious artifact has nothing to steal and nothing to talk to.

Disconnected environments

Scanning a model needs no network at all.

Vulnerability and malware databases are baked into the scanner images at build time. Refreshing them means rebuilding an image — the right trade for a disconnected or classified cluster, where the alternative is a scanner that quietly reports clean because it could not reach its mirrors. The ClamAV step refuses to run against an empty signature database for exactly that reason.

Two deliberately permissive defaults

A gate that blocks everything on day one breaks running clusters, so Zeus ships open and expects to be tightened. --require-report=false admits models that have never been scanned, and the webhook's failurePolicy: Ignore keeps a Zeus outage from blocking all model deployments.

The second is worth stating plainly: Ignore means anyone who can disrupt Zeus can also bypass the gate. Both should move once every model in the registry has a report.
