Model sources

Where models come from, and whether Assay can still see them.

Each row is a ModelRegistryConnector. The operator polls it, opens a scan for every version it has not seen, and writes the verdict back onto the version so the people who registered the model see it where they work.

A source that has stopped answering is the failure worth noticing. It produces no findings and no alarms — the inventory simply stops growing, which looks identical to nothing new being registered. That is why the state and the age of the last sync are on the same row: Connected with a sync from four days ago is not connected.
